# Agent Configuration

This directory contains project rules and guidelines for AI agents working on this project.

## Files
- `development-guidelines.md` - Core project rules, guidelines, and documentation
- `project-overview.md` - High-level project description and architecture

## Usage
Any AI agent can reference these files to understand:
- Project structure and goals
- Coding standards and conventions
- Technical constraints and requirements
- Development processes and best practices

## Guidelines for AI Agents
When working with this project, AI agents should:
1. Always refer to the development guidelines before making any changes
2. Understand the project's architecture and limitations
3. Follow established coding patterns and conventions
4. Prioritize backward compatibility
5. Focus on maintaining existing functionality while enhancing user experience
